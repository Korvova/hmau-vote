МОСТИК «ГОЛОСОВАНИЕ → VEYON»
=============================
Что делает: как только на сайте стартует голосование, на всех ПК депутатов из hosts.txt
открывается страница кабинета делегата http://10.10.200.27:8090/hmau-vote/user
(той же командой Veyon «Открыть сайт», которой открывают повестку, только автоматически).

На ПК депутатов ставить НИЧЕГО не надо. Ставится только на ПК с Veyon Master (у оператора зала),
под тем пользователем Windows, из-под которого работает Veyon Master (у него уже есть ключи доступа).

УСТАНОВКА (Veyon 4.9.7)
-----------------------
1. Скопировать папку veyon-bridge на ПК с Veyon Master (куда угодно).
2. Открыть hosts.txt и проверить список ПК депутатов: по одному адресу в строке, IP или имя как в Veyon.
   Список можно снять с самого Veyon: в PowerShell   & "C:\Program Files\Veyon\veyon-cli.exe" networkobjects dump
3. Если veyon-cli.exe лежит не в C:\Program Files\Veyon\ — поправить путь в bridge.config.json.
4. Запустить install.bat. Он скопирует файлы в %LOCALAPPDATA%\vote-veyon-bridge, добавит ярлык
   в автозагрузку текущего пользователя и сразу запустит мостик (скрыто, без окна). Прав администратора не нужно.
5. Лог: %LOCALAPPDATA%\vote-veyon-bridge\bridge.log. Там видно каждый опрос-ошибку и каждое открытие страницы.

ПРОВЕРКА
--------
a) Связь с сайтом:   powershell -ExecutionPolicy Bypass -File vote-veyon-bridge.ps1 -Once -DryRun
   В логе должно быть «старт…», без «сайт недоступен».
b) Команда Veyon вручную на одном ПК (подставить адрес):
   & "C:\Program Files\Veyon\veyon-cli.exe" feature start OpenWebsite 10.86.13.11 "{\"websiteUrls\":[\"http://10.10.200.27:8090/hmau-vote/user\"]}"
   На том ПК должен открыться браузер со страницей. Если нет — проверить, что этот ПК открывается из Veyon Master вообще.
c) Боевая: запустить тестовое голосование на сайте — на всех ПК из hosts.txt должна выскочить страница.

ВАЖНО
-----
- Мостик работает, пока пользователь на ПК с Veyon Master залогинен (он в автозагрузке этого пользователя).
- Страница открывается в браузере по умолчанию на ПК депутата. Если депутат там уже залогинен — сразу увидит кнопки голосования.
- Окно выводится вперёд средствами Windows; жёсткого «поверх всех окон» здесь нет.
- Удаление: uninstall.bat.
